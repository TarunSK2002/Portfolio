Retail & Wholesale E-Commerce

Sri Mobiles Inventory & Sales Management System

Stack: React, Node.js DB: MySQL Role: Lead Developer

✕ The Business Challenge

The client, a multi-brand mobile retailer, was managing inventory tracking, dealer invoicing, and profit tracking via manual paper ledgers. This resulted in frequent stock-outs of popular phones, untracked profit margins on wholesale dealer trades, and payment collection delays.

⚙ The Engineering Solution

Designed a responsive web application powered by a Node.js API and MySQL database. Implemented a unified database architecture with role-based access control (RBAC) separating wholesale dealers, administrators, and retail customers. Created a real-time inventory ledger module that calculates running stock averages and triggers email/dashboard alarms when stock counts fall below custom threshold levels. Developed a detailed reports dashboard compiling gross sales, vendor expenses, and net profit margins.

🚀 Business Value Delivered
  • 100% Stock Visibility: Eliminated manual count bottlenecks.
  • 90% Shortage Reduction: Automated warning thresholds ensure popular models are always in stock.
  • 15+ Hours Saved Weekly: Automated sales calculations, profit margins, and dealer reports.
React Node.js MySQL RBAC
Enterprise Multi-Branch ERP

Gym Management & Multi-Location Registration System

Stack: MERN Stack DB: MySQL Role: Systems Architect

✕ The Business Challenge

A fitness company with multiple branch locations struggled to monitor candidate registrations, trainer assignments, and monthly member subscription dues from a single interface. Payments were frequently missed, and trainer attendance tracking was unreliable.

⚙ The Engineering Solution

Architected an enterprise-level platform utilizing the MERN Stack and MySQL database clusters. Designed the BranchMasterUI, a modular branch selection and data aggregation control panel. Created relational entities connecting candidate profiles, active trainers, and location IDs. Built a secure subscription tracking system that triggers automated payment alerts and monitors physical check-ins via branch attendance logs.

🚀 Business Value Delivered
  • Centralized Operations: Allowed management to oversee all branches in real-time.
  • 40% Delinquency Reduction: Automated payment notifications and subscription alerts.
  • Faster Check-ins: Reduced administrative bottlenecks during peak facility hours.
React Express.js MySQL BranchMasterUI
